# AI Usage History

Central cost history for implementations **without** a user story file.
Story-based work is tracked inside the respective story under `docs/stories/`.

Costs are estimates produced by [ccusage](https://ccusage.com) from local Claude Code
logs (API-equivalent pricing; on Pro/Max plans this is not billed money), converted to
EUR by the `cost-tracking` skill.
